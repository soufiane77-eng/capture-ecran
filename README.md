# One-Click Screenshot

A lightweight Chrome extension for quickly capturing a selected area of your screen and copying it directly to the clipboard.

Capture an area, then use `Ctrl + V` to paste the screenshot anywhere that supports image pasting.

## Features

* One-click activation from the Chrome extension
* Select any area of the screen
* Automatic screenshot capture
* Automatically copies the screenshot to the clipboard
* Paste instantly with `Ctrl + V`
* No account required
* No server required for the core workflow

## Usage

### 1. Activate the extension

Click the Screenshot extension icon in Chrome.

### 2. Select an area

Click and drag to select the area you want to capture.

### 3. Capture

Release the mouse button. The selected area is captured automatically.

### 4. Paste

The screenshot is copied directly to your clipboard.

Use:


Ctrl + V    You can paste the screenshot into applications such as: 

* ChatGPT
* Discord
* Slack
* Gmail
* WhatsApp Web
* Microsoft Teams
* Google Docs
* Image editors
* Any application that supports image pasting
